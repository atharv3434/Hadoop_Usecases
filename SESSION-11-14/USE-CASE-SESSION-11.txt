# HiveQL Use Case: Airline Flight Analytics

Travel and Aviation Sector

//Problem Statement

An airline company stores large amounts of flight information such as:

* Flight ID
* Airline
* Source
* Destination
* Flight status
* Ticket price
* Number of passengers

The company wants to use Hive to analyze this data and generate business reports.

Using HiveQL, we will:

1. Store flight data in a Hive table.
2. Find all flights.
3. Find flights for a particular airline.
4. Find cancelled flights.
5. Calculate average ticket price.
6. Find the number of flights operated by each airline.
7. Find the average ticket price by airline.
8. Find the highest ticket price.

In:
//sql

`*` means:

> Select all columns from the table.

//For example, if `flights` has:

flight_id
airline
source
destination
ticket_price
passengers


then:
SELECT * FROM flights;


returns all six columns

//Is `SELECT *` good practice?
For learning, testing, and quick exploration: Yes.

In production/interview discussions: Explicitly selecting required columns is generally preferred:
//
SELECT flight_id, airline, ticket_price
FROM flights;


//Why?

* Makes the query clearer
* Avoids retrieving unnecessary columns
* Can reduce data transfer
* Makes queries less sensitive to schema changes
//Interview question

Q: What is the difference between `SELECT *` and selecting specific columns?

SELECT * retrieves all columns from a table, whereas specifying column names retrieves only the required columns. `SELECT *` is convenient for exploration, but selecting specific columns is generally preferred in production because it improves clarity and avoids unnecessary data retrieval.
//
SELECT * 
     ↓
Useful for learning/testing/exploration


SELECT col1, col2
     ↓
Preferred when only specific data is required

# 10. WHERE Condition

//

# 14. GROUP BY

Find the number of flights operated by each airline:

//
SELECT airline, COUNT(*)
FROM flights
GROUP BY airline;
```

//Expected:

IndiGo      3
Vistara     2

# 15. Average Ticket Price

//

FROM flights;

//

20. Flights with Ticket Price Greater Than 6000

//

21. ORDER BY

Display flights from highest ticket price to lowest:

//

22. LIMIT

Display only the first 3 flights:

//

23. Business Analytics Example:
Find the total passengers handled by each airline:

//
SELECT airline, SUM(passengers) FROM flights GROUP BY airline;


This demonstrates a realistic business requirement:

> The airline management wants to compare passenger volume across different airlines.

25. Why Hive for This Use Case?

An airline can generate millions of flight records over time.

//For example:
Flight bookings
Flight schedules
Passenger records
Flight status
Ticket prices
Routes

Instead of manually writing MapReduce programs for every report, analysts can use HiveQL:

//
SELECT airline, COUNT(*)
FROM flights
GROUP BY airline;
```

Hive provides a SQL-like interface while the underlying data can be distributed across Hadoop storage.
